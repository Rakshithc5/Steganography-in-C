# Image Steganography in C

A C application for hiding and extracting messages in image data using the **Least Significant Bit (LSB)** technique.

## Overview
The project explores how data can be embedded in image pixels and later recovered, while learning low-level file processing and bit manipulation.

## Key Concepts
- Least Significant Bit (LSB) encoding
- Bitwise operations and binary data
- File I/O and image data processing
- Modular programming in C

## Project Details
- **Language:** C
- **Focus:** Bit manipulation, file handling, and image steganography
